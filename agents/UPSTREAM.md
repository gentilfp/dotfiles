# Vendored skills

These plain-text skills work in all four harnesses without requiring a separate
plugin lifecycle. Shared instructions activate Ponytail full and Caveman lite;
their native slash commands/intensity instructions remain available as skills.

| Skill | Upstream revision | Source |
|---|---|---|
| Ponytail | `e3ba2aa6f1e6f0bc4d69eb09c9f0d0a93af56156` | https://github.com/DietrichGebert/ponytail |
| Caveman | `2fd153c67988e980fb0b2455c90832159a6a5a25` | https://github.com/juliusbrussee/caveman |

Each directory includes its upstream license. Update `SKILL.md` and its license
from a reviewed revision together, then change this record. Git carries these
exact files to every machine; synchronization never downloads a moving branch.
